# 🤖 OM AI-CHATBOX

A modern AI chatbot application that provides conversational responses using **Google Gemini 2.5 Flash**.

## 🚀 Live Demo

👉 **[Try OM AI-CHATBOX](https://omaichatbox.vercel.app)**

## ✨ Features

- 💬 Conversational AI chat
- 🤖 Powered by Google Gemini 2.5 Flash
- ⚡ Streaming AI responses
- 🎨 Clean and responsive interface
- 🧠 Conversation context
- 🔒 Secure server-side API integration
- 🩺 Built-in API health monitoring

## 🧰 Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Google Gemini**
- **Vercel AI SDK**
- **Tailwind CSS**
